# Python 数据分析课程作业

## 环境

```bash
conda activate pytorch   # 已有的独立 conda 环境（Python 3.11.13），不是 base
code .
```

VS Code 内核选择 `Python 3 (pytorch)`（不能是 base）。

## 目录结构

```
hw01.ipynb      作业1：数据类型、函数与条件
exp01.ipynb     实验1：Python 基础与数据处理入门
student_utils.py  实验1-4 用到的解析模块（由 notebook 生成）
exp01_data/       实验1-4 生成的数据目录
```

## 提交命名

- `学号_姓名_hw01.ipynb`
- `学号_姓名_exp01.ipynb`

提交前需 Restart Kernel → Run All，确保从头可运行。
